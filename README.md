# MERN Chat App

A real-time chat application built using the MERN Stack (MongoDB, Express.js, React.js, and Node.js) with Socket.IO for instant messaging.

## Features
- User Authentication
- Real-time One-to-One Chat
- Responsive UI
- JWT Authentication
- MongoDB Database
- Socket.IO Integration

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Socket.IO
- JWT

## Installation

```bash
npm install
npm start
```
